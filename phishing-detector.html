기반 논문: 「웹페이지 접속 없이 탐지하는 피싱 URL의 형태적 특징(Lexical Features)과 악성 여부의 상관관계」 (2026, 이혜원)

Lexical Phishing Detector

"웹페이지에 접속하기 전 의심스러운 링크의 감염 위험을 피하고 싶은 사용자가 URL을 입력할 때, 11만 건의 보안 연구 결과(URL 29자 이상 임계점, 도메인 내부 하이픈 3.88배 위험 규칙)를 바탕으로 악성 피싱 위험도를 즉시 진단하고 근거를 제시합니다."

이 도구는 외부 서버 통신이나 웹페이지 본문(HTML/JS) 다운로드 없이, 사용자의 브라우저 내부에서 URL 문자열 구조만으로 순수 분석합니다. 제로데이 악성코드 감염 위험 없이 안전하게 진단 결과를 확인하세요.

예시 샘플:
15
안전 수준 (Low Risk)
논문의 피싱 임계 기준을 초과하지 않는 일반적인 형태의 URL입니다.

0 개

하이픈 없음

1 개

• 피싱 URL에서 통계적으로 유의미한 과다 검출

보안 권고사항 (Action Guide)

URL 형태가 안정적입니다. 다만 로그인이나 결제를 요구할 경우 브라우저 주소창의 자물쇠 인증서(HTTPS)와 도메인 철자를 반드시 재확인하세요.
