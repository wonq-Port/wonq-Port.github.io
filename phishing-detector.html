Lexical Phishing Detector

"웹페이지에 접속하기 전 의심스러운 링크의 감염 위험을 피하고 싶은 사용자가 URL을 입력할 때, 11만 건의 보안 연구 결과(URL 29자 이상 임계점, 도메인 내부 하이픈 3.88배 위험 규칙)를 바탕으로 악성 피싱 위험도를 즉시 진단하고 근거를 제시합니다."

외부 서버 통신이나 웹페이지 다운로드 없이 브라우저 내부에서 URL 문자열 구조만으로 분석합니다. 클립보드 원클릭 진단, 정상 vs 의심 URL 1:1 비교(A/B), 최대 500줄 일괄 진단, 실전 피싱 모의 훈련 퀴즈, 누적 통계 대시보드까지 안전하게 수행하세요.

Hypothesis revision

하이픈 가설의 수정

BEFORE · 기각

URL 전체의 하이픈이 많을수록 피싱일 것이다.

AFTER · 지지

호스트 내부 하이픈이 많을수록 피싱 집단에서 높게 관측된다.

경로 하이픈은 정상 사이트의 SEO 관행일 수 있어 점수에서 제외합니다.

Limitations

이 도구가 보지 못하는 것

  1. 단축 URL과 침해된 정상 도메인 짧고 정상적으로 보이는 주소 내부의 피싱은 탐지하기 어렵습니다.
  2. 네트워크 기반 정보 TLS 인증서, WHOIS 도메인 연령, 페이지 본문을 분석하지 않습니다.
  3. 절대 기준이 아닌 29자 dataset6에서는 정상 URL 평균 길이가 더 길어 데이터셋 차이를 확인했습니다.
